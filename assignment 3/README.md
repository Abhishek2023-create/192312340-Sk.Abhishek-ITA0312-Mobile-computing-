# Mobile Computing — Assignment 3 (CO3)

Seven question folders with Python 3 examples and explanatory READMEs. The source document specifies pair work: both students should understand every question and retain their own contributions. These teaching simulations supplement, rather than replace, the architecture diagrams, Mobile IP reasoning, routing pseudocode and collaborative design evidence.

Screenshots are generated by `.github/workflows/generate-assignment-outputs.yml` after successful program execution.
